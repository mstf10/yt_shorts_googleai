# YT Shorts AI Generator

A web studio powered by Google Gemini 2.5 Flash and Pexels for generating viral YouTube Shorts scripts, voiceovers, and 9:16 portrait video previews.

## Features

- **Gemini Storyboard Generation**: Automatically builds 4–6 engaging scene scripts for any topic with hooks and stock video search terms.
- **9:16 Live Shorts Preview Player**: Interactive mobile preview with synchronized karaoke subtitles and stock video playback.
- **Pexels Video Engine**: Fetches stock footage matching each scene's visual query.
- **Interactive Storyboard Editor**: Edit narration scripts, adjust speech speed/voices, reorder scenes, or refresh video clips.
- **Export Capabilities**: Export scripts to JSON schema, Markdown format, or CLI command snippets.

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev
```

Built for AI Studio Cloud Run environment on Node.js 22.
